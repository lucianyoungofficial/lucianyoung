# Dino Runner

The Chrome offline T-Rex runner game, extracted from Chromium source.

## Source

- Original Chromium source: [components/neterror/resources/](https://source.chromium.org/chromium/chromium/src/+/main:components/neterror/resources/)
- Extracted by: [wayou/t-rex-runner](https://github.com/wayou/t-rex-runner)
- The game engine (`index.js`), CSS, sprite assets, and audio are unmodified from the Chromium original
