# Dino Runner

The Chrome offline T-Rex runner game, extracted from Chromium source.

## Source

- Original Chromium source: [components/neterror/resources/](https://source.chromium.org/chromium/chromium/src/+/main:components/neterror/resources/)
- Extracted by: [wayou/t-rex-runner](https://github.com/wayou/t-rex-runner)

## Local changes

- Added procedural footsteps and jump sounds, with cleanup on game over, focus loss, and page changes.
- Adjusted canvas scaling and disabled image smoothing for clearer sprites at fractional display scaling.
- Added click/touch restart support and layout adjustments.

This is a locally modified version. See the root [CHANGELOG](../../CHANGELOG.md) for implementation history. Preserve the upstream attribution and license when updating it.
